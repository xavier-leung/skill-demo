# 两个整数的最小公倍数

从用户请求中取得两个整数；缺少数字或输入不是整数时，请用户补充或更正，不自行猜测。

使用 Python 3 运行本技能目录下的 [scripts/lcm.py](scripts/lcm.py)，将两个整数作为位置参数传入：

```bash
python3 /path/to/skill-test-1/scripts/lcm.py 12 18
```

将 `/path/to/skill-test-1` 替换为本技能所在的实际路径。脚本仅使用 Python 标准库，无需安装依赖。

脚本向标准输出打印计算结果。示例输出为 `36`，向用户回复“12 和 18 的最小公倍数是 36”。

支持正整数、负整数和零：按绝对值计算非负结果；任一输入为零时，结果约定为零。输入数量错误或包含非整数时，脚本输出参数错误并以非零状态退出，此时不要声称计算成功。
