# 角色定妆：整版角色设定图

**默认版式参考使用 [用户已确认的标准示例](images/character-sheet-approved-example.png)**。用户于 2026-11-19 对这张测试图回复“没问题。”，确认其布局及马赛克覆盖程度。首次生成前实际查看该图，优先沿用它的版式、三视图尺度、三个细节区及头部马赛克方式。仅参考这些组织规则，不照搬示例人物的长相、性别、年龄、服装或职业；角色内容来自当前项目已确认设定。此确认仅针对技能版式示例，不替代后续项目中具体角色图的审核。

[原始带红叉示例](images/character-sheet-layout-reference.png) 仅留作需求来源，不再作为默认生图参考。红叉区域已从标准示例中删除，不应重新生成。

## 固定组成

每个角色一张横向整图，anchors.images[].view 为 `character-sheet`。这是一张同一人物的多视图设定板，不是多人合影。

- **左侧约 38% 宽度**：清楚的正面大头照（可带肩部及胸前），完整头发轮廓、面部和肩部，重点辨认五官；这是整张设定图唯一清晰的人脸与发型参考，不打马赛克。
- **右上约 2/3 高度**：同一角色正面、侧面、背面的全身站立图，从左到右排列。三者完整头脚，身高比例一致，共用脚下基线，视角可辨，手臂自然放松。侧面采用真正侧视，背面不能转头变成另一张侧面。三个全身视图的整个头部（包括脸、头发及耳部）均覆盖明显、足够粗的马赛克，保留头部外轮廓和位置以判断身高比例，不遮住颈部以下的衣物。
- **右下剩余区域**：仅三个细节区，按服装领口/胸前材质、双手、鞋子排列并均衡铺满。明确同一套衣服、同一双鞋及同一人物双手。细节图尽量不包含头部；若出现头部，也必须覆盖马赛克。
- **不要单独的头顶、发际线、头发局部小图**。删除该区域后重新分配下排空间，不留空槽，不画红叉，也不要用额外脸部裁切替代。

采用白色或干净浅色背景，细分隔线、统一留白、清晰光照，无剧情环境、无水印、无 UI、无“复制图片”字样。人物本身画风按 brief，不默认复制示例照片风格。设定板为横版，不因最终视频为 9:16 就压成长竖条；保持足够分辨率以看清细节，不自称低清大图已可作身份依据。

## 生成提示词与参考输入

提示词同时写入角色的已确认外貌、服装、材质、识别特征和上述完整布局。左侧大头照固定脸型、发型和年龄感，是唯一身份面貌基准；其他视图只约束同一角色的体型、服装剪裁/配饰/污渍及鞋型，透视变化合理，其头部必须打马赛克。不得要求从被遮挡的脸确认五官一致，也不能让右侧视图露出第二张清晰脸。

生图工具支持参考图片时，传入用户已确认的标准示例，明确“仅借鉴版式与头部马赛克，不借鉴示例身份或服装”。不默认传入原始带红叉图。另有用户提供的真实人物身份参考时，明确其身份作用，避免布局示例覆盖正确的人脸。实际输入记录遵循 image-inputs.md。模型若误把红叉或头发局部图画出，列为 fail 并按原有上限修复。

## 必查项目

每张 character-sheet 的 qc.criteria 需包含以下 critical 项，所有候选逐项观察：

| ID | 检查内容 |
|---|---|
| sheet_layout | 左侧大半身、右上三视图、右下三个细节区，比例清晰且没有空槽、UI、红叉或水印 |
| sheet_identity | 左侧大头照符合身份、年龄及发型设定；其他视图身形、服装与配饰和其对应，不对马赛克内五官作可见性断言 |
| sheet_head_mosaic | 左侧大头照清晰且无马赛克；所有其他视图出现的整个头部均覆盖粗马赛克，五官不可辨认，覆盖不遗漏也不侵入主要服装细节 |
| sheet_views | 正面、真实侧面、背面三个全身视角齐全，完整头脚、统一尺度与脚底基线 |
| sheet_details | 服装、双手、鞋子三个细节清楚且匹配主体，手部解剖及鞋型合理 |
| sheet_no_hair_crop | 不存在独立头顶/头发/发际线小图，也没有另加脸部局部图填该位置 |

仍需原有角色描述验收项、组内状态对照及最多 3 次重做规则。代码只检查记录存在和版本，不自动识别是否画了头发小图；模型必须实际看图。

整张设定图确认后作为身份基准。第 7 步不为凑清单重复生成已有三视图和正脸图；镜头确需单独视角/状态时引用本图生成，并做同组一致性检查。传给分镜/视频工具时明确“多视图仅作身份与服装参考，成片只出现剧本要求的人数，不要把设定板或多个人物视图拍进场景”。额外强调：只从左侧清晰大头照提取脸部和发型，其他视图仅供体型、服装、姿态和尺度参考；马赛克是参考图的遮挡标记，不是角色外貌，输出分镜图和视频中的头脸应自然清晰，不出现马赛克、遮挡块或设定板。不能要求模型从马赛克猜脸来替代清晰大头照。旧 front-full 图继续兼容，不自动改写其历史批准；用户要求更新时制作新图并重新确认。

当角色换装或追加视图时，沿用同一清晰大头照作为脸部基准；用于参考的其他视图照样遮挡头部。需要其他独立清晰脸部参考时须用户另行明确要求，不自行追加第二套人脸基准。马赛克应在角色参考素材生成/编辑环节完成并实际检查，不能仅在 HTML 展示时遮挡而将未遮挡原图传给模型；实际工具输入必须使用已核对的马赛克版本。
