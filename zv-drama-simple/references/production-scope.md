# 第 6 步起的制作范围

第 1–5 步保留文字策划范围。第 5 步确认后、第 6 步生图前，告知用户：“默认仅生成第一集所需素材；也可选择所有集。”用户已明确范围时沿用其选择，未指定就采用第一集，不额外等待一次范围审批。每一步原有的聊天确认仍保留。HTML 只展示范围，不增加选择按钮。

项目根目录 `production-scope.json` 保存 `{"schemaVersion":1,"mode":"first"}` 或 `{"schemaVersion":1,"mode":"all"}`；文件不存在也按 first。first 明确指 E01，不是当前剧本数组的第一项或已有批次的第一集。all 指 brief.episodeCount 中的全部集数，不是当前已写好的部分集数。

```bash
# 查询实际集数和所需人物、地点、道具
python3 {skill}/scripts/workflow.py scope {project}
# 用户选择仅第一集 / 所有集
python3 {skill}/scripts/workflow.py scope {project} --mode first
python3 {skill}/scripts/workflow.py scope {project} --mode all
```

所有集模式要求 script 已包含全剧集数；缺失时先将 brief.scope 扩展、补齐对应剧本并按受影响步骤重新确认，不能用大纲代替剧本推算全剧素材。缺少 E01 时也需先补齐 E01，不能擅自用 E02 代替。

按所选集数的 script.scenes 汇总并去重：characterIds 决定角色锚点/派生图，locationId 决定场景图及俯视图，propIds 决定道具图；场外说话人物也计入 characterIds。需要的不同服装、光照、道具状态仍分别制作，不能因实体 ID 相同丢掉必要变体。角色/场景/道具未在剧本登记时先修正剧本，不临时生出未登记实体。

第 6–8 步只登记并生成选中范围所需实体的图片；第 9 步只排选中场次；第 10–11 步只覆盖选中集数的节拍及镜头；第 12–13 步只生成和剪辑这些分段与集数。第 3–4 步全剧文字设定可含尚未生图的人物地点，不因有设定就生成全剧素材。

改变范围会使第 6 步起已有确认失效，不单独使第 1–5 步失效。重新整理当前 JSON，保留历史及原素材文件；已生成且适用的素材复用，补齐新增项，不覆盖原图、不重置原图片的重做计数。范围缩小时从当前清单移出不需要的记录，原图留存。按现有依赖和图像验收上下文要求重新核对及提交，不能复制旧审批跳过复核。

旧项目无该文件也默认第一集。已有多集生产记录的项目须先告知这项默认值；如用户希望继续原全剧范围，记录 all 后复核，不删除已生成的内容。
