# AI 短剧分镜 Agent 知识库

基础视听语言、连续性剪辑与分镜规则

V1.0  |  研究整理与执行规范

用于其他大语言模型增量优化现有分镜 Skill。输入小说或剧本，输出能够追溯到原文、能按顺序剪接、可逐镜核查的视听方案。

### 基本原则

- 以戏剧节拍组织镜头。先确定观众何时需要知道什么，再安排景别、人物调度和切点。

- 在分镜阶段做预剪辑。设计当前镜头时，同时确定上一镜给出的线索和下一镜需要继承的状态。

- 先保证事实、因果与连续性，再检查镜头是否传达有效信息，最后调整节奏。快节奏来自减少无效过程和重复解释，关键证据、反应与停顿仍需有足够时间。

## 02 文字转分镜工作流

WORKFLOW  |  输入到交付

### WF-01 锁定原文事实

输入剧本或小说、允许的改编范围，以及已给定的画幅和片长。记录版本、原文位置、场次、时间、地点、内外景、人物、目标与阻力、关键对白、道具、伏笔及上下场衔接。每个必须保留的事实分配 ID，并标明观众最早和最迟何时得知。未指定的制作参数标为待定。原文未交代的站位等调度注明「分镜补充设计」。

### WF-02 拆分戏剧节拍

用目标、对抗、发现、决定或局势变化划分节拍。每拍记录触发、行动、结果和观众新增认知。一次动作可跨镜，一镜也可覆盖多拍。心理描写优先寻找与原文等义的表演、动作、对白、声音或视觉证据，区分人物所知、观众所知与待揭示信息。

### WF-03 建立空间图与状态账

固定场景坐标、出入口、人物和关键道具的初始位置，记录谁看谁、谁持有何物、各动作轴的有序端点。多人场景在关注关系改变时更新轴线。另存画面左右、视线方向与入出画边，避免用某一机位的画面位置替代场景位置。

### WF-04 预剪辑与镜头设计

先用镜头序列安排交代、推进、揭示、反应、冲突或转折。逐切点写出观众注意力从哪里到哪里、什么信息需要留下、声音何时起止。再选择能读清关键动作与关系的景别、角度、构图和运动。用试读、表演预演或画面读字校准时长。

### WF-05 校验与返工

先按原文核对事实与节拍覆盖，再逐镜和逐切点核对状态、轴线、视线、动作和声音。按 P0、P1、P2 顺序返工。任何修订后重查受影响节拍、前后切点、状态账、声音覆盖和总时长。未能确定的关键事实进入待确认项。

### WF-06 分镜交付与生成后复检

交付场景地图、节拍、镜头表、声音计划、校验结果与待确认项。生成任务可按模型与素材条件拆分或合并，并以镜头 ID 和片段时间范围建立映射。拿到实际视频后复查起止帧、画外声、接点、读字和一致性。

## 03 景别机位与构图

VIS  |  先识别观众必须看清的内容

### VIS-01 按可读性选择景别

P2-03 / P2-08 · REF-B01/B02/B04/B06，REF-R04/R05

适用  有关键表演、动作、人物关系或物件需要辨认时使用。

执行  先写明观看目标，再选能同时保留动作、反应和必要关系的景别。多人距离、全身动作优先用较宽画面。细微表情可用中近景或近景。关键小字和物件可用插入镜头。

失败  手递钥匙时只拍脸，观众看不见接收者和交接。

修复  用中景容纳双方与手部。钥匙刻字构成线索时，再补可读的细节并保留前后位置。

ELS 大远景 / LS 远景

宏观环境 / 人物与环境、路线。关键表演仍须有可读视点。

FS 全景 / MLS 中全景

人物全身及动作空间 / 常见取景至膝部附近，强调互动与姿态。

MS 中景 / MCU 中近景

常见取景至腰 / 胸部附近，适合对白、操作或表演变化。

CU 近景 / ECU 大特写

脸或主体局部 / 更小细节。用构图范围解决不同 Skill 的译名差异。

Insert 插入镜头

镜头功能，可采用不同景别。记录它补充的证据和回接关系。

### VIS-02 按关系选择机位与构图

P1-01/P1-02/P1-06 · REF-B02/B04/B06

适用  空间首次出现、人物重排、视线需要回接，或画幅改变时使用。

执行  默认从能交代关系的机位和自然视高开始。记录拍摄侧、目标、取景范围、画面重心和动作余量。高低角度、过肩或主观视点须服务于明确的观看关系。按实际交付画幅检查人物、道具、手势与文字。

失败  两个对话近景均看向右，且画面从未交代两人相对位置。

修复  先建立可辨认的双人关系。沿同一轴侧拍两人，按视点分别填写画面朝向。

## 04 摄影机运动

VIS  |  运镜由观看任务触发

### VIS-03 为运动写出起点和目的

P2-04 · REF-B02/B04/B06

适用  镜头计划使用推进、拉远、摇、移、跟拍、环绕或变焦时使用。

执行  默认 static。需要运动时记录起止构图、被跟随或揭示的对象、触发时刻、运动理由及切出状态。通过固定构图即可读清信息时，优先保留固定机位。比较连续揭示与直接切出时的观看差异。

失败  每次人物紧张都推镜，推近还裁掉了关键手势。

修复  保持固定中景直至手势完成。若需要观众逐渐注意到人物隐瞒反应，再安排明确起止的推进。

推进 Dolly in

改变机位，逐渐集中注意或收窄观看范围。需保留关键动作。

拉远 Dolly out

改变机位，揭示环境或人物处境。需要看到信息逐步出现时使用。

横摇 Pan / 俯仰 Tilt

在原机位转动。跟随横向或上下动作，也可揭示画外对象或高度。

移动跟拍 Tracking

机位随行动位移。明确路线、屏幕方向与停止位置。

环绕 Orbit

展示相对关系或改变视点。跨越动作轴时，必须让观众看清方向如何改变。

变焦 Zoom

从固定机位改变焦距与取景范围。透视由机位决定，物理推进会改变机位与透视。

### VIS-04 检查运动的可执行性

P0-08/P1-03 · 工程约定

适用  同一镜头里存在人物位移、显著运镜、生成约束或后续切点依赖时使用。

执行  用起止状态核对路径、遮挡、轴线和可用时间。过轴运动只有在画面能持续交代关系时才用于重建方向。

失败  指定固定机位，同时要求绕人物半圈。镜头结束时角色左右互换，且过程不可见。

修复  选定一种机位方案。必要时用可辨认的双人画面重建新轴侧，再接后续镜头。

## 05 剪辑动机与声音

EDT  |  切点设计与校验入口

### EDT-01 让切镜跟随戏剧重心

P2-01/P2-05 · REF-B02/B03/B05/B07/B08

适用  产生新信息、心理变化、行动重点转移、观察对象改变、关系重组、时空省略、事件并行或声音引导时使用。

执行  写出切入与切出的观看任务。直接切可作为默认候选。画面已能连续完成任务时保留镜头。对白可停在听者身上，画外保留说话人的话。

失败  争吵双方每句台词轮流切近景，观众错过听者发现对方撒谎的表情。

修复  保留一段双人画面或听者反应。把切点放在证据出现或态度转变处。

### EDT-02 保留因果与信息顺序

P0-05/P1-08/P2-06 · REF-B01/B02/B05，REF-R02

适用  反应、悬念、闪回、并行叙事或时间省略涉及前后依赖时使用。

执行  分别记录事件实际顺序与观众获知顺序。保留观众理解结果所需的触发信息。省略可推断且无后果的过程，注明时间变化和跨越后的状态。悬念可延迟声源或解释，写明先给出的线索和回收点。

失败  角色还未收到证据便表现出已经识破。省略离场过程时也删掉了掉落钥匙的伏笔。

修复  将反应移到接收线索后。保留掉钥匙或能等义交代其遗失的线索。

### EDT-03 分轨安排声音与画面

P0-07/P1-07 · REF-B01/B03/B05

适用  镜头有对白、画外声、场景环境声、动作同步声或有意义的沉默时使用。

执行  对白绑定说话人及声音区间。连续空间保留环境声逻辑。撞击等音效标同步锚点。J-cut 让下一段声音先入，L-cut 让上一段声音延续。必要时记录听者何时听到声源、何时看见它。

失败  门关闭后声音晚到且无叙事动机，或切到听者后给听者错误口型。

修复  将门声锁定在关门动作。把台词标为原角色画外声，注明画面中的听者闭口反应。

## 06 短剧信息密度与节奏

PAC  |  先分配信息与表演时间

### PAC-01 按贡献精简镜头

P2-01/P2-02/P2-06 · REF-B02/B03/B08，REF-R02

适用  镜头重复同一信息，或者文字含日常过程、环境铺陈、心理反复时使用。

执行  记录每镜的信息或表演贡献，可多选交代、推进、揭示、反应、冲突、转折。逐镜尝试删除或合并，核对事实、因果、方向和反应是否仍成立。保留伏笔、误会来源、关键道具和关系变化。

失败  已看到角色抵达公司，前面仍完整展示穿鞋、下楼与乘车，过程无剧情作用。

修复  保留出发决定和抵达。若途中发现被尾随，保留这一事件及可理解的线索。

### PAC-02 给读字和反应留出时间

P0-08/P2-07 · REF-B03/B08，REF-R03/R04/R06

适用  有长对白、画面文字、复杂动作、反转或关键沉默时使用。

执行  以试读、表演预演和目标画幅的读字测试确定下限。可并行的声画任务按各自覆盖区间计算，串行任务按实际顺序安排。允许长短交替。片长不足时先减重复，再调整时长或提交取舍。

失败  给观众不到一秒读完整协议，同时要求看清人物反应并听完长句。

修复  缩小必读信息范围、单独给证据可读时间、保留反应并重新试读。压缩不承载信息的铺垫。

### 样本数据的使用边界

Aktaş 对 ReelShort 十部剧集首集的描述性分析报告平均镜头时长 2.31 秒，中景占主导，全景、远景与建立镜头较少。该观察可用于比较同类样本。跨平台、题材或画幅的通用时长阈值需要另行验证。［REF-R06］

Cutting 等分析的是历史好莱坞电影中镜头长度序列的结构。Agent 据此把时长分布作为复核对象。单个镜头时长仍由该拍的信息与表演决定。［REF-R03］

## 07 P0 原文与状态

P0  |  阻断交付  |  任何未解决项均须返工或待确认

### P0-01 关键事实与对白覆盖

WF-01/WF-02 · 工程门禁

适用  原文或用户指定了必须保留的事实、对白、线索或伏笔。

执行  建立保留项到节拍和镜头的映射，核对内容、表达方式与获知时间。指定逐字保留的对白须逐字检查。

失败  分镜删去「合同昨晚已撤回」，后续人物行为失去依据。

修复  恢复原句或经授权的等义证据，回查后续依赖的节拍。

### P0-02 人物场景与关键资产一致

REF-B02/B04 · 工程门禁

适用  人物、地点、服装、关键道具或环境跨镜重现。

执行  用稳定 ID 核对身份、场所、外观和已建立的环境基线。变化须对应原文或已标注的场内事件。

失败  同一连续对话中，甲从制服变成便装，会议室突然成为走廊。

修复  对齐场景与资产基线。有明确换装或换场时，更新状态并提供时空线索。

### P0-03 连续动作阶段衔接

REF-B02/B05/B07，REF-R02 · 工程门禁

适用  同一物理动作跨镜，或下一动作依赖前一动作结果。

执行  比较同一 action_id 的执行者、手、接触点、方向与阶段。允许剪辑素材保留重叠，但成片时间线只展示需要的动作阶段。

失败  前镜已经拧开瓶盖，后镜又从瓶盖锁紧开始。

修复  把前镜切到拧动中，后镜接同一只手完成。也可以直接从开盖后接续。

### P0-04 道具持有与状态变化

REF-B02/B05 · 工程门禁

适用  关键道具跨镜出现、移动、开启、破损或更换持有者。

执行  核对道具的位置、持有者、手、开合、数量和可见变化。遮挡或出画仍须延续其实际状态。

失败  上镜手机在甲右手，下镜突然出现在乙左手，期间无转移线索。

修复  补拍可读的交接，或维持甲右手状态。将后续镜头同步改为正确状态。

## 08 P0 因果与可执行性

P0  |  原文事实和物理关系优先于风格

### P0-05 核对关键因果

EDT-02 · REF-B01/B02，REF-R02

适用  结果依赖前置事件，或涉及悬念、非线性呈现或并行事件。

执行  核对故事时间和观众获知顺序。表现顺序可重排，原因、人物实际所知及解释回收须自洽。

失败  人物听见从未发生的铃声，随后才有第一次响铃，且文中无预示。

修复  补上刺激或重排切点。原文指定先果后因时，保留结构并提供时间和回收线索。

### P0-06 核对人物实际位置

WF-03 · REF-B02/B04

适用  人物移动、出入场或在相邻镜头中处于已知位置。

执行  比较场景坐标和可通行路径。机位变化可改变画面左右，人物实际位置仍须连续或有可解释的时间省略。

失败  门外的人在同一时刻出现在锁住的房间内。

修复  让进入路线、开门或可推断的时间跳跃成立；或者将人物放回门外。

### P0-07 核对关键台词归属

EDT-03 · REF-B01/B03

适用  有关键对白、口播、电话、旁白或跨镜声音。

执行  比对原文说话者、声音轨上的角色 ID 与画面口型计划。画外对白允许跨镜，归属须清楚。

失败  妻子说「我已经签字了」，却标记为丈夫的台词。

修复  改回妻子的角色 ID。若声音覆盖丈夫画面，标记妻子画外、丈夫反应。

### P0-08 核对动作时长与生成约束

VIS-04/PAC-02 · 工程门禁

适用  有预算时长、并行或串行动作、指定机位或下游模型约束。

执行  检查能否在既定时长内完成动作、表演、试读与关键读字，核对镜头和生成片段的起止状态、格式及任务限制。

失败  2 秒内要求先读短信，再跑到门边并完整说完三句台词。

修复  重分配时间或拆任务。保留必要事实，重新核算镜头和全段时长。依赖未确认时先标待确认。

## 09 P1 轴线视线与屏幕方向

P1  |  修正或提交有画面证据的例外

### P1-01 保持或重建 180 度动作轴

REF-B02/B04/B05，REF-R01

适用  同一对话或动作的相邻镜头共享一条轴，或人物重排产生新轴。

执行  记录 axis_id、有序端点和机位所在侧。同轴默认同侧。若必须跨越，让镜内运动展示跨越过程，或用能看清相对位置的镜头重建方向。

失败  A 画左看右、B 画右看左。换机位后双方方向突然反转。

修复  回到原侧。若新视点必要，先用双人关系镜或可读的过轴运动确立新侧。轴上镜头只有提供足够方向线索时才可作桥接。

### P1-02 匹配视线与对象

REF-B02/B04，REF-R01

适用  人物看向画外，或两个镜头暗示角色互看。

执行  记录视线对象 ID、画面方向、高低及人物位置。关键对象可用「看向 → 对象 → 反应」，也可在同一画面完成。

失败  人物向下看桌面，下一镜却让观众以为他看向楼上窗户。

修复  核对机位、对象与人物高度。需要时先把人物和对象置于同镜，或修正眼线后回接。

### P1-03 保持运动方向与出入画关系

REF-B02/B04/B05

适用  人物沿同一路线跨镜移动，或出现反向、转弯、换视点。

执行  匹配角色的场景路径、屏幕方向和画框边缘。方向改变须能由转身、转弯、视点重建或换场解释。

失败  人物向右跑出画，下一镜又从右侧进入并向左跑，观众误以为折返。

修复  延续向右的运动，或拍清转弯和新的路线。

### P1-04 避免意外跳切

REF-B05，REF-R05

适用  相邻镜头主体、动作状态、构图和角度均相近。

执行  检查新镜是否提供足够视点或信息变化。30 度是传统实践提示，按观看效果判断。

失败  同一句话中突然切到几乎相同的头部画面，人物像瞬间抖动。

修复  合并，或切到确有信息价值的反应、关系画面。若刻意用跳切压缩时间，记录目的与辨识线索。

## 10 P1 姿态空间声画与信息

P1  |  造成关键事实丢失时按 P0 处理

### P1-05 保持朝向与身体姿态

REF-B02/B05

适用  同一时刻跨机位，或镜头省略角色姿态转换。

执行  核对肩线、头部朝向、站坐、手势和正在进行的动作。必要时在同镜展示变化，或给出可推断的动作过渡。

失败  前一镜举手发问，反打切回时手臂已垂下且无时间经过的线索。

修复  让手在可见时间内落下，或将切点移到动作之后。

### P1-06 提供必要的空间交代

VIS-02 · REF-B02/B04/B06

适用  首次进入空间、第三人加入、出口改变或旧关系难以推断。

执行  交代观众理解下一动作所需的相对位置、出入口或距离。可通过双人构图、移镜、动作或多个有线索的镜头完成。

失败  追逐双方都只用面部近景，无法判断谁堵住了出口。

修复  补一个包含出口和双方位置的关系镜，或在有效动作中交代路线。

### P1-07 核对声音与画面时序

EDT-03 · REF-B01/B03/B05

适用  同步声、画外声、J-cut、L-cut、环境声或沉默跨越切点。

执行  检查声源、听者、同步锚点和声音区间。声音先入或延续时，记录是哪一个声源及听者何时能听见。

失败  同一房间反打时环境声反复消失。人物在声音发生前被意外安排作出听觉反应。

修复  保持同一环境声逻辑，校正同步锚点。刻意的主观静默需写明触发点及恢复方式。

### P1-08 补齐理解下一镜的线索

EDT-01/EDT-02 · REF-B01/B02，REF-R01/R02

适用  切换视点、空间、时间、事件，或离开一个正在进行的动作。

执行  用盲读检查观众能否凭现有声画解释「谁、看哪里、为何发生」。若丢失原文关键事实，同时触发 P0-01 或 P0-05。

失败  从人物伸手切到陌生房间里的门锁，观众无法判断两镜关系。

修复  增加可识别的连接线索、明确换场或换回可理解的切点。

## 11 P2 镜头价值与视听选择

P2  |  按上下文提出优化

### P2-01 检查每镜贡献

EDT-01/PAC-01 · REF-B02/B08

适用  镜头的功能无法描述，或切除后观众得到的信息完全一样。

执行  试删该镜，检查必要空间、关系、因果、节奏停顿或反应是否仍完整。

失败  人物已经认出照片，下一镜再次拍同一照片，且无新线索。

修复  合并镜头，或让第二次出现揭示先前没看见的关键信息。

### P2-02 消除无效重复

PAC-01 · REF-B02/B03

适用  台词、旁白、字幕、物件与反应反复传达同一事实。

执行  标记重复通道。保留承担确认、冲突、讽刺或补充信息的重复，压缩仅复述的表达。

失败  画面清楚写着「已签字」，旁白原样重述，台词没有增加立场。

修复  按原文保留要求选择表达。必要时让画面提供事实，台词揭示态度。

### P2-03 景别匹配叙事重心

VIS-01 · REF-B02/B04/B06，REF-R04

适用  镜头重点从身体动作、人物关系转为表演细节，或反向变化。

执行  检查现有画面是否能让观众找到并识别重点。景别变动应有信息或表演理由。

失败  证人沉默时唯一的关键眼神藏在拥挤远景里。

修复  选中近景，或清理原构图让关键眼神清楚可读。

### P2-04 移除无动机运镜

VIS-03 · REF-B02/B04/B06

适用  计划连续使用推进、拉远、摇移、跟拍、环绕或变焦。

执行  要求每次运动给出观看任务和起止画面。用固定镜头试读并比较。

失败  人物静坐读信，摄影机无目的左右晃动，文字无法读清。

修复  固定画面，让表演或信息本身成为重心。

## 12 P2 对白省略与节奏

P2  |  若时间不足以完成指定内容则升级 P0-08

### P2-05 避免逐句正反打

EDT-01 · REF-B02/B03/B07

适用  两人对话连续换镜，切点恰好总落在换说话人时。

执行  识别冲突和心理转折。结合双人画面、说话者、听者和画外对白组织镜头。

失败  A 说一行切 A，B 接一句切 B，语气与信息变化均未被强调。

修复  把切点留给关键揭示。让普通攻防在双人画面或听者镜头中连贯发生。

### P2-06 省略可推断的日常过程

PAC-01/EDT-02 · REF-B02/B03

适用  行走、开门、坐下等过程完整占用多个镜头。

执行  检查过程中是否发生关键状态变化。可省略时保留出发状态、到达结果和必要的时间地点线索。

失败  从楼上走到门口拆成四镜，期间没有阻碍或新信息。

修复  切到到达门口。若必须交代钥匙遗失，保留遗失线索及其后果。

### P2-07 留出反转的识别时间

PAC-02 · REF-B03/B08，REF-R03/R06

适用  证据出现、局势反转或人物做出关键决定。

执行  用试读和预演验证观众有时间接收事实及理解结果。分别检查读字、台词、停顿与反应。

失败  证据一闪而过就跳场，观众尚未明白它为什么能推翻前述说法。

修复  延长可读证据或补等义台词，给关键反应留出辨识时间，回收无效铺垫的时长。

### P2-08 检查景别使用是否失衡

VIS-01 · REF-B02/B04/B06，REF-R04/R05

适用  连续使用同类特写或宽景，造成信息遮蔽或空间关系重复。

执行  检查现有景别是否仍适合该拍的观看任务。连续使用同类景别本身可保留。

失败  双人争执连续切眼睛大特写，关键递物动作和站位缺失。

修复  合并重复特写，给递物和空间关系一个清晰构图。

## 13 场景节拍与镜头字段

DATA  |  映射到现有 Skill 的同义字段

项目与场景

project_id、source_revision、scene_id、source_ref、地点与内外景、story_time、aspect_ratio、时长目标、相邻场连接。

原文保留项

fact_id、原文位置、要保留的事实或台词、speaker_id、保留方式、揭示窗口、对应 beat_id / shot_id。

节拍

beat_id、场景与原文引用、触发、人物目标、行动、结果、观众新增认知、依赖与保留项。

空间地图

actor_id / prop_id、位置锚点、可通行路径、初始朝向与姿态、持有者、axis_id 与有序端点、默认机位侧。

镜头身份

scene_id、shot_id、sequence_index、source_ref、beat_ids。ID 稳定，顺序修改使用 sequence_index。

叙事与画面

function 列表、information、subject、shot_size、framing、camera_angle、camera_movement、movement_reason。

连续性

axis_id、axis_side、screen_position、screen_direction、eyeline、start_state、end_state。状态以人物、道具和动作 ID 索引。

剪辑与声音

入出理由、时间关系、估计时长或待定状态。音轨含声源、说话者、台词、区间、画内外、环境声、音效与同步锚点。

校验与生成映射

validation、findings。generation_map 可选，记录 task_id、shot_id、片段区间、素材引用及剪入剪出范围。

### 字段约定

以原文位置追溯事实，以稳定 ID 连接记录。用 source_fact、staging_proposal、unknown 区分原文事实、补充调度和未知。unknown 须附待确认原因。null 表示该字段在当前记录中无值，并由状态字段区分待定与不适用。

片内时间以秒记录，定版可另存帧率和整数帧。同一连续切点默认从前镜结束状态继承。跨时间、空间或轴线时记录变化的起因及观众能察觉的线索。

相邻镜头按 sequence_index 比较。每个切点按「原文保留项 → 时间关系 → 空间与动作 → 声画覆盖 → 新增贡献」复核。出现一个根因触发多条规则时，问题记录保留主规则与关联编号。

## 15 从原文到镜头的示例

CASE  |  发现离婚协议

原文「林浩推门进入办公室，看到桌上的离婚协议。他愣住，抬头望向妻子。妻子平静地告诉他，她已经签字了。」

### 原文保留项与补充调度

F01 进入办公室，F02 看到离婚协议，F03 愣住并看妻子，F04 妻子确认已签字。对应节拍 B01 到达、B02 发现、B03 认知变化、B04 确认。将「我已经签字了」作为示例的对白化表达。门在左、妻子坐桌后在右、协议在桌面、机位同侧，均为补充调度。

SH01 · MLS · 交代

林浩推门入画并停在门边，妻子在桌后。林浩低头看桌面，切向其注意对象。办公室底声延续。

SH02 · Insert · 揭示

让协议标题可读，文件仍在桌上。观众先知道协议是什么，签署事实留给下一拍的台词。

SH03 · CU · 反应

接林浩向下的视线。他愣住、抬眼看妻子。保持站位，切向妻子。

SH04 · MCU · 转折

妻子回看林浩，平静说「我已经签字了」。此镜承载 F04，声音在妻子处起。

SH05 · CU · 可选反应

留在林浩身上观察确认之后的变化。若与 SH03 的愣住重复，可在 SH04 结束。新增动作标为补充调度。

### 校验与修复演练

P0-01 核查 F01–F04 覆盖于 SH01–SH04。P0-04 跟踪协议留在桌上。P0-07 校对 SH04 的说话者。P1-01 比较轴侧。P1-02 检查 SH01 低头接桌面、SH03 抬眼接妻子。P2-07 试读标题并预演台词。P2-02 对照 SH05 是否产生了与 SH03 不同的反应。

失败方案把 SH02 的签名先作为反转，又让 SH04 重复相同结论。若节拍要求由妻子完成确认，SH02 只确保标题可读，SH04 再给签署事实。若原文明确要求先看到签名，则保留该揭示并评估妻子台词是否还承担确认或态度信息。

## 16 序列模板与增量接入

INTEGRATION  |  用现有输出接口验证规则

双人对话

交代两人关系 → 承载对白和攻防 → 必要反应。重点查 P1-01、P1-02、P0-07、P2-05。

发现秘密

异常线索 → 证据 → 反应。重点查 P1-02、P0-05、P2-07。

普通物理动作

建立动作关系 → 动作执行 → 结果。重点查 P0-03、P0-04、P1-03。

进入新场景

进入或直接到达 → 必要空间 → 主要事件。重点查 P0-06、P1-06、P2-06。

冲突与反转

关系 → 对抗 → 新信息 → 关键反应。重点查 P0-05、P1-08、P2-07。

### 在既有 Skill 中接入

保留原有入口、字段、输出格式和用户指定的制作边界。先建立同义字段映射，再分别把规则放入六个模块：剧本分析、镜头语言、连续性、剪辑逻辑、短剧节奏和质量检查。可用内部校验记录承接现有输出无法容纳的字段。

生成轮按节拍设计镜头，复核轮只依照原文、空间图和镜头记录逐条找证据。先修 P0，直到阻断项为零。P1 逐项修正或记录例外与可见线索。P2 记录收益与取舍。以问题清单验收，保留各级别的独立状态。

### 五组回归用例

分别以对话争执、发现秘密、进出场、递物、冲突反转测试。每组保留原文、预期事实与空间状态、修订前后镜头和复检结果。可在副本植入错误，验证是否定位对应 ID。

- 对话争执中交换说话人或轴侧。预期分别报 P0-07、P1-01。

- 发现秘密时移除关键证据或反转观看时间。预期报 P0-01 或 P2-07。

- 进出场中让人物越过未交代的障碍。预期报 P0-06，空间线索不足另报 P1-06。

- 递物时换手或跳过持有权转移。预期报 P0-03 或 P0-04。

- 反转中把反应放到人物获知前。预期报 P0-05。

通过基础用例后，再接生成模型、首尾帧、参考图与时间线。编辑镜头以观看任务和切点定义，模型任务以生成能力和素材边界定义，两者通过映射对齐。
