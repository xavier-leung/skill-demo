# 图片展示与用户确认（旧验收流程已移除）

本分支不执行 Agent 图片验收、打分、候选比较、组内/相邻图冲突审核、俯视图专项验收或最多三次自动重做。此规则覆盖 anchors、assets、floorplans、frames，包括角色设定图、道具图、场景状态图、俯视图、分镜关键帧和首尾帧。

生成前仍读取已确认设定、参考图和知识库，准备正确提示词及真实参考输入。生成后登记当前文件、prompt、referenceIds；脚本只验证文件、图片格式、ID、制作范围、引用、布局数据与镜头空间约束，不评价图片是否符合描述。

图片完成后提交所在步骤、展示 HTML，在聊天中等待用户确认。用户要求修改时才修改对应图片，以新文件名保留历史，再重新展示。不自动多次生成后选最优，不需要 qc.checked、criteria、attempts 或验收指纹。

旧图片 qc 对象允许保留但不读取、不展示、不用于通过或拒绝提交；其中候选文件不再作为生产依赖。旧 image_review.py 命令仅返回停用说明，不能继续运行原验收流程。

视频片段与成片的观看、试听、QC 和用户确认不变；小说转换完整性核对、文本方案检查和基础数据校验也保留。
