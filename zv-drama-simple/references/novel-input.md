# 任意格式输入，统一 Markdown 正文

## 唯一小说参考源

无论用户交付 TXT、MD、Word、PDF、EPUB、网页、图片、其他文件或直接粘贴文本，都先转换为项目内 **`source/novel.md`（UTF-8）**。已有 Markdown 也归一到此路径。

输入格式可以任意，但不能声称所有文件都能直接、无损自动提取：损坏、加密、扫描、图文混排和缺少读取工具的文档，先使用适合的文档读取或 OCR 能力，核对完整结果后再进入制作。不得只改扩展名，也不得用摘要、故事梗概或模型补写替换完整正文。

**输入转换阶段结束以后，凡需要小说参考，只读取 `source/novel.md`。** 大纲、人物分析、美术设定、剧本、分镜、原文引文核对及恢复制作都遵守。其他已确认 JSON/图片仍是正常制作输入，但不能被称为小说原文。原始附件、聊天中的重复粘贴、阅读摘要和旧格式文件不再作为后续小说依据。

## 输入归档与转换

先初始化项目，然后执行：

```bash
python3 {skill}/scripts/import_novel.py import {project} '/输入路径/小说.txt'
# 需要明确文本编码时：--encoding gb18030
```

内置转换：

- TXT/MD：支持 UTF-8、带 BOM 的 UTF-16，或明确指定编码；尝试 GB18030；不使用 errors=replace 丢字符。
- HTML/XHTML：保留正文文字、标题和段落，排除 script/style。生成后必须核对导航、广告、分页内容是否混入或缺失。
- DOCX：按正文 XML 顺序提取段落和表格内文字；修订、插图文字、复杂结构需要核对。
- EPUB：按 spine 阅读顺序提取章节，不按文件名字母顺序拼接。
- PDF：当前环境有 pdftotext 时提取文本层；必须核对扫描页、分栏顺序、缺页和页眉页脚。纯扫描页不能因为其他页有文本就算成功。
- ODT/RTF/FB2/RST/TEX：当前环境有 pandoc 时可转换；同样需要内容核对。

其他格式、扫描件或工具不可用时，用当前可用的格式读取/OCR能力先提取**完整正文**到临时 UTF-8 MD，再登记：

```bash
python3 {skill}/scripts/import_novel.py import {project} '/输入路径/原文件.pdf' --converted '/临时路径/完整提取.md'
```

用户粘贴文本：先原样保存临时 TXT，再用 import 归一。网页 URL：取得用户指定小说的实际完整正文后按 HTML/文本输入；不能把导航页面当小说，也不能根据书名脑补缺章。多卷输入先确认顺序，保留各卷原文件，完整拼接成一份规范 MD；缺失范围必须解决或由用户明确调整改编范围。

脚本归档原文件到 source/originals，写 conversion.json 记录来源、转换方法、字符数、警告和哈希。归档只用于溯源，后续脚本不重新读取原文件。转换只是初稿，verified 默认为 false。

## 完整性核对

只在这个输入阶段对照原附件与转换结果，确认：

1. 首尾内容、章节数量和顺序正确，没有重复或缺页、漏章。
2. 正文和对白完整；没有以摘要替换长段内容，没有凭空补写。
3. 编码正确，中文、人名、标点可读；OCR 易错字及断行已核实。
4. 页眉页脚、广告等非正文内容已处理；正文中的题记、脚注、插图文字是否承载情节，应有明确处理。
5. 未能确认的部分必须先解决或说明阻塞，不能填写 verified=true 跳过。

检查完成、必要修正写回规范 MD 后：

```bash
python3 {skill}/scripts/import_novel.py verify {project} --notes '实际核对范围、方法和结果'
```

verify 只记录模型已完成的内容核对和当前哈希，不会自动证明转换无损，也不是额外的用户审批。用户仍在 brief 步骤查看制作要求与转换摘要并确认。

brief.sourceFile 固定写 `source/novel.md`。所有后续校验会检查这一约定、UTF-8 正文及核对状态。正文/转换记录纳入版本指纹；修改规范 MD 后须重新核对，重新提交受影响的制作步骤，旧确认不继续沿用。

## 修改和恢复

已有项目的规范正文不会被 import 自动覆盖。用户补充/纠正文稿时，先保留旧 MD，再在输入修订阶段整理到同一份 source/novel.md，重新 verify。不要让后续步骤同时参考两份不同的小说版本。

旧项目如 sourceFile 仍为 TXT/PDF，先走转换、核对，将 brief.sourceFile 改为固定 MD 路径后重新提交 brief。旧确认和旧图片检查指纹需要按依赖重新核对，不能只改路径绕过确认。

长篇可以分段读取同一个 MD；进度记录只能记章节和位置等索引。需要核对事实或引文时回读该 MD 对应段落，不用中间摘要替代正文。
