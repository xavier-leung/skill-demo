# 同一实体的状态图分组

用稳定 entityId 组织同一人物 Cxx、道具 Pxx、场景 Sxx 的状态，每张图使用独立素材 ID，view 写清状态与视角。换衣、换角度、昼夜变化不是新实体。

生成前读取同组设定和相关参考图，在 prompt 写清不变项、允许变化及剧情依据。人物保持身份、体型与服装特征；道具保持形状、材质与比例；场景保持门窗、家具与空间关系。参考图实际输入遵循 [依赖图规则](image-inputs.md)。

assets.referenceIds 可引用同角色锚点、数组中更早的同实体素材或已登记相邻场景；不允许自引用、向后循环引用、无依据跨人物/道具引用。每个场景只使用一张俯视图，其他状态复用。

共享已确认基准且互不依赖的状态可并发生成，合计最多 5 个在途任务；依赖前态时串行。结果串行归档到 JSON，不执行生成后的组内交叉验收，不追加 group_* 检查项，不自动重做旧图或新图。

步骤 HTML 与 reports/asset-library.html 按 entityId 展示所有状态和俯视图，由用户确认。用户提出状态冲突或修改要求时再修订；生产素材变化仍按步骤指纹使相关用户确认失效。分镜按剧情顺序组织，引用对应状态，避免使用错误的剧情阶段。
