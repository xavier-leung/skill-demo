# 两个整数的最大公约数

使用 Node.js 脚本计算两个整数的最大公约数，支持负整数、零和大整数，无需安装第三方依赖。

从用户请求中取得两个整数；缺少数字或输入不是整数时，请用户补充或更正，不自行猜测。

运行本技能目录下的 [scripts/gcd.js](scripts/gcd.js)，将两个整数作为位置参数传入：

```bash
node /path/to/skill-test-2/scripts/gcd.js 12 18
```

将 `/path/to/skill-test-2` 替换为本技能所在的实际路径。运行环境需要支持 BigInt 的 Node.js（10.4 或以上版本）。

脚本向标准输出打印计算结果。示例输出为 `6`，向用户回复“12 和 18 的最大公约数是 6”。

按输入的绝对值计算非负结果；一个输入为零时，返回另一个输入的绝对值；两个输入均为零时，结果约定为零。大整数应原样作为十进制字符串传入，不转换为浮点数。

输入数量错误，或输入含小数、科学计数法等非十进制整数格式时，脚本输出错误并以非零状态退出，此时不要声称计算成功。
